# 背单词・四六级 ·AI ·词典

一个面向大学英语四 / 六级的**单文件 H5 背单词应用**，内置全量真题词频词书与完整释义数据，并接入 DeepSeek 大模型提供讲解、成文、提取、出题、学情等 AI 能力。无需安装、无需服务器，一个 HTML 文件即可部署使用。

在线体验：[https://dfind-sun.github.io/vocab2/](https://dfind-sun.github.io/vocab2/)



***

## 一、设计理念：算法调度 + AI 生成

这个应用遵循一条明确的分工原则：



* **算法负责效率**：复习调度（艾宾浩斯遗忘曲线）、词频统计、难度分级、去重、积分结算全部由本地算法完成 —— 快、免费、可离线。

* **AI 负责内容与理解**：语境讲解、生词筛选判定、短文辅助背词、开放出题、学情诊断 —— 这些是算法做不好、但对学习价值很高的环节，交给大模型。

所有 AI 调用都遵循**点击触发、可缓存、按积分计量**的成本控制原则，不点不花、同词复用、每次调用都控制在极小 token 量级。

## 五、AI 工程细节（调教与成本控制）

这是本作品作为「AI 应用」的核心技术内容，重点解决两个问题：**AI 幻觉** 与 **调用成本**。

**1. 防幻觉：本地权威数据注入 prompt**



* 单词卡片内置本地权威音标、中文释义、动词英英释义（WordNet 词表，覆盖词库 3000+ 动词）。

* 每次调用 AI 讲解 / 出题 / 成文前，把该词的权威释义注入提示词，并要求：*「必须严格以单词背景中给出的本地权威音标、释义和英英释义为准，不得超出或编造其他含义，也不得把别的词的释义安到这个词上」*。

* AI 只负责在权威数据之上展开例句、记忆法、语境，从源头压住「张冠李戴」式幻觉。

**2. 成本控制策略**



* **点击触发**：AI 入口全部是手动按钮，用户不点就不调用，不产生任何消耗。

* **同词缓存**：AI 讲解生成后写入本地缓存，再次遇到同一个词直接读缓存，不重新调 API、不重复扣积分；设置中可一键清除。

* **两段式生词提取**：AI 提取生词不把整篇文章丢给模型 —— 先用本地分词与词表匹配做初筛，只把候选词和上下文句子交给 AI 做「对当前水平是否值得学」的判定，token 消耗大幅降低。

* **输出约束**：所有提示词都限定输出格式（严格 JSON）与长度（讲解释义截断至 280 字以内），避免模型长篇输出浪费 token。

* **按积分计量**：每次 AI 调用消耗 2–8 积分，积分由背词 / 复习 / 游戏赚取，形成「学习产出 — AI 消费」的自洽循环，天然限制滥用。

**3. 交互打磨**



* AI 讲解再点一次可收起，讲解内容在卡片内联展示，不打断背词节奏。

* 所有 AI 请求带加载状态提示，失败时给出具体原因与重试指引，不出现「点下去没反应」的卡死状态。

## 六、技术亮点



* **单文件架构**：HTML + CSS + JavaScript 全部内联，词库数据以压缩字符串内嵌，开箱即用，无任何外部依赖。

* **数据本地化**：学习进度、生词本、积分、词书数据全部存于浏览器 localStorage，支持一键导出 / 导入备份，换机不丢数据。

* **词库工程**：四 / 六级词频来自历年真题统计，支持按「去高考词」等条件裁剪词书，聚焦真正需要背的词。

* **AI 集成**：前端直调大模型接口，所有请求带加载状态与失败友好提示。

* **可定制**：支持导入 txt /json 自定义词书，AI 提取生词自动创建新词书。

* **AI 功能提示网络失败？** 检查网络是否可访问 `api.deepseek.com`（国内网络通常可直接访问）。
